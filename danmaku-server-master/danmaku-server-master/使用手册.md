# 元火弹幕姬 使用手册

> 把 QQ 群消息实时采集并显示为网页弹幕，可用于现场大屏 / OBS 投屏。
> 适用系统：Windows 10 / 11（64 位）

---

## 一、这是什么

采集链路如下：

```
QQ群消息  ->  NapCat(QQ机器人)  ->  弹幕服务  ->  网页弹幕 / OBS投屏
             OneBot协议 5099        过滤·去重       WebSocket 5098
```

需要记住两个端口：

| 端口 | 用途 | 是否需要对外开放 |
|---|---|---|
| 5098 | 弹幕网页、给 OBS / 浏览器访问 | 局域网内开放即可 |
| 5099 | 接收 NapCat 推送的群消息 | 只在内部使用，不对外开放 |

---

## 二、运行前提

1. Windows 10 / 11 64 位
2. 已安装 **Docker Desktop**（未安装请看第三章）
3. 一个用于登录的 **QQ 号**（建议使用小号，需已加入目标 QQ 群）
4. 电脑可以正常联网

---

## 三、首次安装环境

### 3.1 解压项目

把整个项目文件夹解压到任意位置，**路径可以是中文或带空格**，不影响运行。

### 3.2 双击 `安装环境.bat`

脚本会自动完成：

1. 检查是否安装了 Docker Desktop
   - 未安装：自动打开官方下载页，安装完成后重新双击本脚本
2. 启动 Docker 引擎（若未运行）
3. 写入国内 Docker 镜像加速配置
4. 重启 Docker Desktop 使配置生效
5. 校验镜像源是否生效

> 只需在第一次使用时运行一次。看到「环境配置完成」即可进入下一步。

### 3.3 如果没有安装 Docker Desktop

1. 到 https://www.docker.com/products/docker-desktop/ 下载并安装
2. 安装过程中若提示需要启用 WSL2 / 重启电脑，按提示操作
3. 重启后重新双击 `安装环境.bat`

---

## 四、启动与扫码登录

双击 **`start.bat`**，按提示操作。

### 4.1 输入两个信息

| 提示 | 填什么 | 说明 |
|---|---|---|
| 请输入用于扫码登录的 QQ 号 | 机器人的 QQ 号 | 该号必须已在目标群内 |
| 请输入要采集弹幕的 QQ 群号 | 目标群号 | 注意是群号，不是群名 |

> 第二次运行时会自动带出上次填过的值，直接按回车即可沿用。

### 4.2 首次构建（仅第一次较慢）

脚本会拉取镜像并编译弹幕服务，首次可能需要数分钟，请耐心等待。
之后再启动会使用缓存，速度很快。

### 4.3 扫码登录

1. 脚本会自动弹出一个 **NapCat 日志窗口**
2. 窗口里会出现二维码（ASCII 图形），用 **手机 QQ** 扫描
3. 扫描后 **务必在 2 分钟内** 在手机上点击「确认登录」

> 登录失败时脚本会自动重新生成二维码，最多重试 5 次。
> 每次重试会新开一个日志窗口，请扫描**最新弹出窗口**里的二维码。
> 如果二维码图形显示错乱，可复制日志里「二维码解码URL」到二维码生成网站再扫。

### 4.4 登录成功的标志

- `danmaku-server` 日志窗口出现 `onebot: connection from ...`
- 群里有人发消息时，日志滚动出现 `群号 -> 昵称: 内容`

登录成功后脚本会自动打开弹幕显示页。

## 五、查看弹幕

### 5.1 本机查看

```
http://localhost:5098/群号
```

### 5.2 局域网其他设备查看

```
http://本机局域网IP:5098/群号
```

查看本机 IP：`Win + R` 输入 `cmd`，执行 `ipconfig`，找「IPv4 地址」。
手机 / 其他电脑需与本机处于同一网络。

### 5.3 调试页（可手动发弹幕测试）

```
http://本机IP:5098/client/群号
```

以列表形式显示弹幕，底部可输入内容手动发送，便于提前测试大屏效果。

## 六、投屏到现场大屏

### 方式 A：直接投屏（纯弹幕墙）

1. 电脑连接投影仪，设置为「扩展屏幕」
2. 打开弹幕页 `http://本机IP:5098/群号`
3. 把浏览器窗口拖到投影屏幕，按 `F11` 全屏

### 方式 B：OBS 叠加（推荐，弹幕叠在画面/背景上）

1. OBS 来源栏点击 `+`，选择「浏览器」
2. 填写：
   - 网址：`http://本机IP:5098/群号`
   - 宽度 / 高度：与输出分辨率一致（如 1920 × 1080）
3. 在「自定义 CSS」框中粘贴以下内容，使背景透明：

```css
body { background-color: rgba(0,0,0,0); margin: 0; }
```

4. 点击「确定」，把该浏览器源放到画面最上层
5. OBS 中选择「全屏投影」输出到投影仪

> 没有单独的文件需要修改，CSS 直接粘贴到 OBS 浏览器源的「自定义 CSS」输入框即可。
> 若预览仍是白底，确认 CSS 粘贴位置正确，并重新切换一次场景。

## 七、更改弹幕样式（颜色 / 字号 / 速度 / 字体）

### 7.1 推荐：通过网址参数修改（立即生效，无需重启）

在弹幕页网址后添加参数即可：

```
http://本机IP:5098/群号?defaultColor=blue
```

可用参数：

| 参数 | 默认值 | 说明 |
|---|---|---|
| `defaultColor` | white | 弹幕颜色，支持 CSS 颜色值 |
| `defaultSize` | 40 | 字号，单位像素 |
| `speed` | 144 | 滚动速度，单位像素/秒（数值越小越慢） |
| `font` | sans-serif | 字体 |

示例：

```
蓝色、字号 60、速度 120：
http://192.168.1.100:5098/123456?defaultColor=blue&defaultSize=60&speed=120

浅蓝色：
http://192.168.1.100:5098/123456?defaultColor=%2355AAFF
```

颜色写法说明：

| 写法 | 效果 |
|---|---|
| `defaultColor=blue` | 标准蓝 |
| `defaultColor=red` | 红色 |
| `defaultColor=yellow` | 黄色 |
| `defaultColor=%2355AAFF` | 十六进制色（`#55AAFF`，`#` 必须写成 `%23`） |
| `defaultColor=rgb(0,150,255)` | RGB 写法 |

> 在 OBS 中使用时，直接把这个带参数的网址填进「浏览器」来源的网址栏即可。

### 7.2 永久修改默认值（需重新构建）

如需每次打开都默认是蓝色，编辑 `frontend/index.html`，找到：

```javascript
defaultColor: z.string().catch('white'),
```

改为：

```javascript
defaultColor: z.string().catch('blue'),
```

保存后在项目目录执行：

```powershell
docker compose up -d --build
```

> 注意：网址参数优先级高于源码默认值，两者同时存在时以网址参数为准。

### 7.3 一个特殊提示

页面刚打开时出现的「**元火弹幕姬已连接~**」是页面内置提示，颜色固定为浅粉色，**不受上述颜色设置影响**；只有真实 QQ 群弹幕才会应用你设置的颜色。


## 九、常见问题排查

### Q1：页面只显示「元火弹幕姬已连接~」，群里发消息没有弹幕

原因：NapCat 未登录成功，或未连上弹幕服务。

排查顺序：

1. 查看 NapCat 日志是否还在输出二维码 / 报 `Login Error`
2. 查看弹幕服务日志是否有 `onebot: connection from ...`
   - 没有：NapCat 没登录成功，重新扫码登录
   - 有：检查群号是否填对（必须与机器人所在群一致）

### Q2：扫码后提示 `Login Error, ErrType: 1 ErrCode: 3`

二维码超时。重新扫描新生成的二维码，并在手机上 **2 分钟内确认**。

### Q3：扫码后提示 `Login Error, ErrType: 1 ErrCode: 5`

账号被风控或开启了登录保护。可尝试：

1. 关闭手机 QQ 的「登录保护 / 设备锁」
2. 换一个注册时间较长、有正常使用记录的老号
3. 先用手机热点网络登录，成功后再切回原网络

### Q4：拉取镜像失败（registry-1.docker.io 连接超时）

双击运行 `安装环境.bat`，重新配置国内镜像加速后重试。

### Q5：其他设备打不开弹幕页

1. 确认两台设备在同一网络
2. 放行防火墙端口（管理员 PowerShell）：

```powershell
New-NetFirewallRule -DisplayName "Danmaku 5098" -Direction Inbound -LocalPort 5098 -Protocol TCP -Action Allow
```

3. 校园网 / 公共 WiFi 可能启用了「AP 隔离」，设备之间无法互访。
   现场建议：用手机开热点，服务器与投屏电脑都连接该热点。

### Q6：某些弹幕不显示

弹幕服务内置三道过滤：

| 过滤 | 规则 |
|---|---|
| 长度限制 | 超过 50 字符的弹幕会被丢弃 |
| 屏蔽词 | 命中 `assets/blacklist.txt` 中任一正则即丢弃 |
| 去重 | 由 `DANMAKU_DEDUP_WINDOW` 控制，默认 -1 表示不去重 |

### Q7：想换一个群采集

直接修改弹幕页网址中的群号即可，机器人需已加入该群。
或重新运行 `start.bat` 并填写新的群号。

## 十、打包分发给其他人

### 10.1 必须排除的内容

| 排除项 | 原因 |
|---|---|
| `napcat\` 文件夹 | 内含本机 QQ 登录会话，与设备绑定，带过去反而会触发风控 |
| `.env` | 可选排除，首次启动会自动重新生成 |
| `docker-compose.yml` | 可选排除，首次启动会自动重新生成 |

> `napcat\` 排除后不影响使用：OneBot 配置文件由脚本自动生成，登录会话在对方扫码后由 NapCat 自动生成。

### 10.2 接收方使用顺序

```
1. 双击 安装环境.bat   （安装/检查 Docker + 配置镜像加速，仅需一次）
2. 双击 start.bat       （部署服务 + 扫码登录 + 开始采集）
```

> 镜像加速配置保存在各自电脑的 `C:\Users\<用户名>\.docker\daemon.json`，
> **不会随项目文件夹一起打包**，所以接收方必须执行一次 `安装环境.bat`。

## 附录：环境变量说明

配置位于 `.env`：

| 变量 | 默认值 | 说明 |
|---|---|---|
| `ACCOUNT` | 无 | 机器人 QQ 号 |
| `RUST_LOG` | info | 日志级别，排查问题可改为 debug |
| `DANMAKU_LISTEN` | 0.0.0.0 | 监听地址 |
| `DANMAKU_PORT` | 5098 | 弹幕网页端口 |
| `DANMAKU_PRIVATE_PORT` | 5099 | 上游推送端口（勿对外暴露） |
| `DANMAKU_DEDUP_WINDOW` | -1 | 去重窗口（秒），-1 为不去重 |
| `DANMAKU_MAX_LENGTH` | 50 | 单条弹幕最大字符数 |
