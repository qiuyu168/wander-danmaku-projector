# 0.2.1 屏蔽词与计数调整

本机配置新增 `moderation.keywords`，旧配置加载时补为空列表，保持原来的群号、样式、二维码等设置。列表保存在现有用户配置文件中，全群共用。校验最多 500 个字符串，每词最多 80 字；保存时去除首尾空白、空行和完全重复项。

投屏窗口在媒体下载、内容聚合和轨道排队之前执行关键词检查。消息摘要和按顺序拼接的文字段均参与匹配，防止拆分成多个文字段绕过检查。采用 Unicode NFKC 规范化和小写后的字面包含，不执行正则。图片 URL 和文件标识不作为正文检查；不做 OCR，也不具备所有谐音、插字、图片辱骂的识别能力。

保存设置后过滤器立即更新，移除当前活动与等待中的匹配实体。被移除实体标记失效，异步图片下载完成后也不能重新上屏。匹配的新输入计入 `blocked`，不增加 combo；已经上屏后因新规则移除的历史实体不追溯扣减累计显示统计。本地测试弹幕仍可用于调试，不计入过滤统计。此项只影响客户端透明投屏，不修改后端旧网页或 QQ 原始消息。

计数字号由 `.55em` 增大至 `.75em`，40 DIP 正文对应 30 DIP 计数。保留固定宽度徽章，按实际外框参与轨道防碰撞；本地特效预览同步放大。固定预留宽度变大会略微降低不同内容的轨道容量，先保证计数可读与不重叠。

新增测试覆盖中英文包含、大小写、全角、字面符号、图文文字段拆分、图片 URL 不误拦截、旧配置默认值及关键词数量/长度限制。GUI 测试新增已有弹幕立即清除、真实后端合成 WS 输入拦截/放行、拦截统计和计数字号边界检查；不向 QQ 群发送消息。

2026-11-12 验证结果：类型检查、12 项单元测试、0.2.1 打包版 GUI 检查通过，最终截图警告为 0。GUI 验证了 ×101 的字号比例及无裁切、运行中新增屏蔽词移除已显示消息、新 WS 输入大小写拦截与正常放行；二维码、GIF、66/100 特效及 QQ 官方 CDN 下载回归通过。测试结束后恢复原有用户配置。HDMI 和现场可读性仍需实际投屏确认。
