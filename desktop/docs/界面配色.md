# wander 界面配色

更新：2026-11-12。

参考北京林业大学官网实际使用的绿色，而非将网页取色称为学校 VI 标准。

| 色彩 | 值 | 用途 |
| --- | --- | --- |
| 主绿 | `#006534` | 品牌文字、主要按钮、滑块、焦点 |
| 官网辅助绿 | `#136335`、`#2A6239`、`#63A775` | 官网参考色；叶片色与辅助层次 |
| 深林绿 | `#164C35` | 页面主视觉，自行搭配 |
| 米白 | `#F5F6F0` | 页面底色，自行搭配 |
| 浅叶绿 | `#EDF3E9` | 章节编号、状态和按钮悬停，自行搭配 |
| 暖金 | `#B59A62` | 少量细节，自行搭配 |

来源：[北京林业大学官网](https://www.bjfu.edu.cn/)、[首页样式](https://www.bjfu.edu.cn/css/index.css)、[通用样式](https://www.bjfu.edu.cn/css/style.css)。访问时首页样式的导航/内容使用 `#006534`、`#136335` 等绿色；通用样式包含 `#2A6239` 与 `#63A775`。

界面采用自绘叶片与 w 组合图形，不使用学校校徽。配色仅应用于控制面板、托盘及定位提示；用户保存的弹幕颜色保持原设置，投影背景保持透明。

名称统一为小写 **wander**：窗口标题、控制面板、托盘、测试文字、便携包目录和说明。技术包名 `danmaku-projector`、Rust 服务名与 Docker 容器名保留，避免影响已有部署。

新的设置目录为 `%APPDATA%/wander`。首次启动仅复制旧 `%APPDATA%/元火弹幕投屏/settings.json` 到新目录，旧目录保留；后续保存使用新目录。QQ 登录数据仍在原服务目录，名称更改不移动登录数据。
