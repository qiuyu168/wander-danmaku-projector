# wander 弹幕姬

将 QQ 群消息变成投影画面上的实时弹幕，为校园活动增添互动。

## 关于我们

大家好，我们是 **北京林业大学 wander 动漫社**！

这款弹幕姬为社团活动中的现场互动而制作。观众在 QQ 群里发送消息，文字、图片和表情包就能在屏幕顶部滚动显示，适用于晚会、放映、讲座和其他需要观众参与的场景。

项目提供本地桌面控制面板，采用北林绿色系配色，支持透明置顶、鼠标穿透和多屏投影，无需 OBS 即可使用。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| QQ 群消息投屏 | 接收指定群的消息，登录账号自己发送的群消息也能上屏 |
| @ 成员名称 | 优先显示群名片，其次显示昵称；查询失败时显示“群成员” |
| 顶部滚动弹幕 | 默认使用屏幕顶部约四分之一的区域，可调整为 10%～50% |
| 透明置顶与鼠标穿透 | 弹幕叠加在桌面、PPT 或视频上方，鼠标可以操作下方的程序 |
| 多屏选择与自动适配 | 支持主屏和第二块显示器，屏幕插拔或分辨率改变后自动调整位置 |
| 自定义样式 | 调整弹幕颜色、随机配色、字体、字号、速度、透明度和文字阴影 |
| 图片与表情包 | 支持文字与图片混排，支持 PNG、JPEG、静态 WebP、GIF 和部分 QQ 表情 |
| 多个 GIF 同时播放 | 同屏动画数量可调，最高 16 个；大型 GIF 自动缩小优化，必要时显示静态首帧 |
| 按需聚合 | 默认相同内容达到 6 条且画面拥挤时才合并为大号 `×N`，空闲时优先独立显示 |
| 互动特效 | 默认在聚合计数达到 66、100 时触发炫彩效果，阈值和动态效果可调整 |
| 过载保护 | 防碰撞轨道与有界队列减少重叠和积压，高峰时会丢弃部分过期消息 |
| 屏蔽关键词 | 包含任意已设置关键词的弹幕整条屏蔽，活动中保存即可生效 |
| 入群二维码展示卡 | 导入群二维码图片，自定义标题、说明、位置和尺寸，按群保存 |
| 现场控制 | 支持清空、暂停、显示/隐藏、全局快捷键和系统托盘 |
| 本地测试与诊断 | 测试文字、图片和互动效果，查看连接状态及延迟统计；测试不会向 QQ 群发送消息 |

## 安装与使用

### 1. 准备电脑和 QQ 群

- 使用 Windows x64 电脑，建议 Windows 11；系统须满足当前 Docker Desktop 的运行要求。
- 建议至少 8 GB 内存，同时运行 PPT、视频等软件时建议 16 GB，并为 Docker 和镜像预留足够磁盘空间。
- 准备一个已经加入活动 QQ 群的 QQ 账号，以及该群的群号。
- 首次安装和 QQ 登录需要联网；校园网请先完成网络认证。

客户端运行依赖 Docker Desktop 和 WSL 2。使用完整便携包时，不需要额外安装 Node.js、npm 或 Rust。

### 2. 获取并解压客户端

打开本项目的 [Releases 页面](https://github.com/qiuyu168/wander-danmaku-projector/releases)，在发布附件中下载 **完整 Windows 便携包**。如果尚未提供附件，请联系项目维护者获取完整包。

GitHub 的 **Code → Download ZIP** 和 Releases 中自动生成的 **Source code** 是源码，不是可直接运行的客户端安装包。

把完整包解压到普通可写目录，例如 `D:\wander`。请完整解压所有文件，不要直接在压缩包里运行，也不要只取出 `electron.exe`。

### 3. 首次安装运行环境

1. 双击解压目录里的 **首次安装.bat**。
2. 按提示允许所需的管理员授权，安装脚本会检查并准备 WSL、Docker 和弹幕后台。完整包提供官方 Docker、WSL 安装程序；缺少的 QQ 接入镜像通过国内镜像源下载。
3. 如果提示需要重启，请保存工作后重启电脑，随后**再次运行“首次安装.bat”继续安装**。
4. 按提示完成 Docker Desktop 首次设置，等待 Linux 引擎就绪。
5. 安装完成会打开客户端；以后也可以双击 **启动弹幕投屏.bat** 打开它。

如果提示硬件虚拟化未开启，需要先在电脑 BIOS/UEFI 中启用 Intel VT-x 或 AMD-V/SVM，再继续安装。首次准备镜像可能需要一些时间，请在活动前完成安装。

### 4. 登录 QQ 并连接群消息

1. 在 **01 消息来源** 中填写登录 QQ 账号和目标 QQ 群号。
2. 点击底部 **保存并应用**，再点击 **启动 / 连接服务**。
3. 等待服务启动，点击 **显示登录二维码**，用手机 QQ 扫码并确认。
4. 确认面板显示 **QQ 在线**，且 **OneBot 已连接**。已登录时无需再次扫码；二维码过期后可以刷新登录。

### 5. 开始投屏

使用投影仪或第二块显示器时，推荐按以下步骤操作：

1. 连接 HDMI 等显示线缆，按 **Win + P → 扩展**。
2. 把 PPT 或视频放到第二块屏幕，主屏保留控制面板。
3. 在 **02 投影显示器** 中选择目标屏幕，调整顶部区域，点击 **保存并应用**。
4. 点击 **在所选屏幕定位区域** 检查显示位置，然后点击底部 **开始投屏**。
5. 在 **03 弹幕样式** 中点击 **在投影上测试**，确认显示正常后，请群成员发送消息验证实际效果。

只有一块屏幕时，也可以选择主屏测试。投屏过程中切换分辨率、拔插显示器或切换复制/扩展模式，客户端会自动适配并保持原来的显隐状态；目标屏断开时可能暂时回到主屏。

“复制”模式会让主副屏显示同样的画面，弹幕也会出现在两边。鼠标穿透可以继续操作下面的软件，但视觉上仍有遮挡；希望主屏保留操作画面、副屏展示内容时，请使用“扩展”模式。

### 6. 设置互动内容

| 面板位置 | 可以做什么 |
| --- | --- |
| **03 弹幕样式** | 设置统一颜色或随机配色，以及字体、字号、速度、透明度和阴影 |
| **04 入群展示卡** | 点击“导入 / 更换二维码图片”，填写标题和说明，再点击“显示到投屏” |
| **05 表情包与图文弹幕** | 开关图片、QQ 表情和 GIF，设置同时播放动画的上限 |
| **06 重复聚合与互动** | 设置开始合并条数、匹配窗口，以及 66、100 等互动阈值 |
| **07 屏蔽关键词** | 每行填写一个关键词，点击底部“保存并应用”后立即生效 |

这里导入的是 **QQ 群入群二维码**，与前面的 **QQ 登录二维码** 不同。请用手机实际扫描展示卡，确认二维码清晰、有效且指向正确的群。

### 7. 日常使用与现场控制

日常使用只需打开 Docker Desktop、等待引擎运行，再双击 **启动弹幕投屏.bat**。进入面板后确认连接状态，点击 **开始投屏**，无需每次运行首次安装。

- **清空**：清除当前弹幕和等待队列，后续消息正常显示，二维码卡保留。
- **暂停新弹幕**：在屏内容继续滚动，新消息暂停接收，恢复后不会补播。
- **立即隐藏**：隐藏弹幕和二维码卡，并清空等待队列。
- **Ctrl + Alt + D**：默认显示/隐藏快捷键，可在面板中更改。
- **关闭面板**：客户端保留在系统托盘，双击托盘图标可重新打开。
- **退出客户端（保留服务）**：退出桌面程序，QQ 与弹幕后台继续运行。
- **停止本项目服务**：在“连接诊断与延迟统计”中停止 QQ 和弹幕后台。

## 使用提示

- **没有弹幕**：先确认 QQ 在线、OneBot 已连接、群号正确且账号已入群，再检查是否开始投屏、暂停或设置了屏蔽词。可以先用本地测试判断显示是否正常。
- **图片没有加载或 GIF 变成静态图**：可能是链接失效、网络超时、格式不支持或超出处理预算；同屏动画达到上限后也会显示静态首帧。不能保证所有 QQ 特殊表情完整还原。
- **QQ 要求安全认证**：请在手机 QQ 按提示完成认证。保持网络和登录数据稳定，避免连续刷新登录；第三方接入无法保证永不断线或免安全验证。
- **弹幕过密**：可以减小字号、提高速度、扩大顶部区域或调整聚合设置。过载保护会舍弃部分消息，以免队列持续积压。

## 源码来源

本项目的弹幕后台基于北京大学元火动漫社的开源项目 **元火弹幕服务**：

- 上游仓库：[PKUOriginalFire/danmaku-server](https://github.com/PKUOriginalFire/danmaku-server)
- 原项目许可证：[Apache License 2.0](https://github.com/qiuyu168/wander-danmaku-projector/blob/main/danmaku-server-master/danmaku-server-master/LICENSE)

在上游项目基础上，本仓库增加了 wander 桌面客户端，并扩展了透明投屏、多屏适配、图文与 GIF 处理、重复弹幕聚合、互动效果、关键词屏蔽和二维码展示等功能。感谢原项目作者与开源社区提供的基础。

项目主要使用 Electron、TypeScript、Preact 和 Rust，QQ 消息通过 [NapCatQQ](https://github.com/NapNeko/NapCatQQ) 的 OneBot 接入。上游及各项第三方依赖的许可证分别适用，原项目许可文件保留在对应源码目录。
